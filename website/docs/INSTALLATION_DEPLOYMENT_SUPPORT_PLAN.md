# Plan installation / deployment / support

## Objectif
Avoir un process clair pour installer, verifier et depanner le portail web.

## Installation
- Mode offline avec build standalone.
- Service Windows via WinSW.
- Fichier env unique dans `.next/standalone/.env`.

## Verification post-install
- Presence des fichiers Next (`.next/standalone`, `.next/static`).
- Service Windows running.
- Logs WinSW disponibles.

## Support
- Portail hotline pour diagnostic.
- Acces aux logs serveur web et serveur C#.
- Logs filtrables par jour.
