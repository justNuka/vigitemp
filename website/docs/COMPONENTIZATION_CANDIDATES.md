# Candidats a la componentisation

Derniere mise a jour : 2026-01-12

## Objectif
Identifier les pages trop longues ou complexes pour les decouper en composants.

## Criteres
- > 300 lignes par page.
- Logique metier melangee au rendu.
- Composants reutilisables detectes.

## Liste a completer
- Utilisateurs
- Groupes
- Lieux
- Surveillance
- Admin (onglets)
